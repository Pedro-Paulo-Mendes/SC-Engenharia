## 💻 Sobre o Projeto
Uma Landing Page moderna, responsiva e otimizada desenvolvida para a **SC Engenharia**, uma empresa especializada em projetos estruturais, execução de obras e laudos técnicos. 

O objetivo do projeto foi criar uma presença digital forte, profissional e voltada para a conversão de clientes, com integração direta para atendimento via WhatsApp.

🔗 **[Acesse o site rodando ao vivo aqui!](https://pedro-paulo-mendes.github.io/SC-Engenharia/)**

## ✨ Funcionalidades e Destaques Técnicos
* **Design Responsivo:** Interface fluida que se adapta perfeitamente a smartphones, tablets e desktops.
* **UX/UI Otimizada:** Navegação suave (Smooth Scroll) e menu mobile estilo "hambúrguer" construído com Vanilla JS.
* **Integração com WhatsApp API:** Botão flutuante e CTAs dinâmicos que redirecionam o usuário diretamente para o contato comercial com mensagem pré-definida.
* **Conformidade com LGPD:** Banner de consentimento de cookies interativo, que salva a preferência do usuário no `localStorage` do navegador.
* **SEO e Acessibilidade:** Estrutura semântica, meta tags configuradas, favicon personalizado e arquivo `sitemap.xml` para indexação rápida no Google.
* **Formulário de Contato Dinâmico**: Integração com a API do Formspree para envio automatizado de e-mails, permitindo a captação de leads e orçamentos diretamente para a caixa de entrada da empresa, sem a necessidade de construir e hospedar um back-end próprio.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica.
* **CSS3:** Estilização com Flexbox, Grid Layout, variáveis CSS e Media Queries.
* **JavaScript (Vanilla):** Lógica de interação do menu, rolagem de página e sistema de cookies, sem dependência de bibliotecas externas.
* **Hospedagem:** GitHub Pages.
* **Integrações de Terceiros**: Formspree API (para o roteamento do formulário de contato) e WhatsApp API.
